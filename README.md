# Python Desktop Scripts

A collection of Python scripts for automating and simplifying everyday desktop tasks.

---

## Description

**Python Desktop Scripts** is a repository of lightweight, standalone Python utilities designed to run on your desktop. Each script focuses on a single task, so you can use only what you need without installing a large framework.

**Highlights**

- Simple, single-purpose scripts that are easy to read and modify
- Minimal dependencies
- Run directly from the command line or by double-clicking (where supported)
- Easy to extend with your own scripts

**Getting Started**

```bash
# Clone the repository
git clone https://github.com/<your-username>/python-desktop-scripts.git
cd python-desktop-scripts

# (Optional) Install dependencies
pip install -r requirements.txt

# Run a script
python script_name.py
```

---

## Compatibility

| Requirement      | Supported                                      |
| ---------------- | ---------------------------------------------- |
| Python           | 3.8 or newer                                   |
| Windows          | Windows 10 / 11                                |
| macOS            | macOS 11 (Big Sur) or newer                    |
| Linux            | Most modern distributions (Ubuntu, Fedora, etc.) |

**Notes**

- Some scripts may rely on OS-specific features. Any platform limitations are noted at the top of the individual script.
- Using a virtual environment is recommended:

  ```bash
  python -m venv venv
  source venv/bin/activate    # Windows: venv\Scripts\activate
  ```
